# Getting help with dctx

Start with [installation and quick start](README.md#installation), the
[documentation index](docs/README.md), and the [map guide](docs/guides/MAP-MODE.md).
Run `dctx --help` (or `dctx-cli --help` for Cargo installs) for current commands.

For usage questions, reproducible bugs or feature ideas, search
[GitHub issues](https://github.com/Eris-Margeta/dctx/issues), then open an issue
with the appropriate template. Questions are welcome as blank issues; GitHub
Discussions is not required. Include the version, OS/architecture, install method,
exact command and sanitized output. A tiny synthetic example helps us reproduce it.
Do not attach confidential code, credentials or private context exports.

Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
Community help is offered as time permits, with no guaranteed response time.
Companies needing agreed response times or long-term support can use a
[maintenance agreement](MAINTENANCE.md). For code or documentation contributions,
see [CONTRIBUTING.md](CONTRIBUTING.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).
