# Desktop distribution

The desktop app is free and open source under Apache-2.0, copyright Eris Margeta.
The current Tauri preview and planned GPUI rebuild use the same project license.
See [LICENSE](../LICENSE) and the root [NOTICE](../../../NOTICE).

## Downloads and builds

The [GitHub Releases](https://github.com/Eris-Margeta/dctx/releases) page is the
source of published artifacts. Check each release's asset list and notes for
available packages; CLI archives do not imply desktop installers are available.
Build the Tauri preview using [BUILDING.md](BUILDING.md).

Platform signing, notarization and updater support must be verified for each
published desktop release. A source build does not establish signed installer
availability or platform qualification. The [testing guide](../../../docs/TESTING.md)
describes CLI and library CI; its matrix excludes desktop packages.
