## 5. Proposed removal order

Candidate packets below have literal file own sets; NEW means proposed, not existing evidence. Deletion waits for announced compatibility/import acceptance (docs/design/ARCHITECTURE-PROPOSAL.md:413). All commands are **future predicates**, not scout runs. Implementation workers run targeted checks; final integration runs the full suite once at end (docs/design/ARCHITECTURE-PROPOSAL.md:451). Every packet additionally requires diff scope checks/positive-refusal controls. Shared files serialize through listed dependencies; small integration exceptions avoid padding ownership.
Dispatch must separately authorize exact validation-artifact paths and arrange isolated Cargo lock/build outputs; leaf packets must not silently update root Cargo.lock.
