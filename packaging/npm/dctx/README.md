# dctx

Registry publication is coming soon. For now, install a prebuilt archive from
[GitHub Releases](https://github.com/Eris-Margeta/dctx/releases). After publication,
install with `npm install -g dctx` or run `npx dctx`.

The matching native executable is an optional dependency. Supports Linux (static musl)
and macOS on x64/ARM64, and Windows x64. Keep optional dependencies enabled.
No install scripts or postinstall downloads are used.
