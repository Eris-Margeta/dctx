The baseline for choosing dctx is grep plus reading files. Count the whole agent session before claiming a cost saving. Output bytes and estimated output tokens measure only the returned context; they exclude startup instructions, tool descriptions, conversation replay, model output and provider cache effects.

Grep plus file reads#

The headline baseline is grep plus reading files. A controlled benchmark against it, counting whole agent sessions, is being prepared and will be published with raw data; no result is claimed here yet.

Secondary historical evidence: other-tool protocols#

Everything below retains the October/November research record, including its older limitations and plans. These other-tool comparisons are historical notes, not the product's headline baseline or a recommendation between tools. All "tokens" in these tables mean estimated tool stdout tokens, calculated as ceil(stdout_bytes / 3.5), never whole-session tokens. Task scores are fact coverage in raw outputs without a model, not agent completion rates.

One command, same host, same corpora, same CPU set, no network, pinned versions. Raw aggregate, headline tables and the harness are in research/bench-3way-20261030/; the current goals are in the specification. Where another tool wins, the tables say so.

  • dctx: main at ac8408c (the following commit only changes CHANGELOG.md), release build, sha256 82bd48760932305748a00d2b32901c667af948f602822b9816cc5c545de7ebbc. Baseline for "before" columns: main at 4660f6d, the state before this night's work.
  • Trail-Code @trailhq/trail-code 0.28.0 from npm, trail build . (no --deep, no --lsp).
  • graphify graphifyy 0.9.97 from PyPI, LLM-free code path only (extract --code-only, GRAPHIFY_BACKEND=none). Its LLM pass over docs, PDFs and images was not run, and nothing here measures it.

Method#

  • Host: a Linux benchmark host (Debian 13, Xeon E5-2680 v2), shared with other jobs. Load was 3.2 at the start, so absolute latencies are noisy. Every measured command ran as nice -n 10 taskset -c 24-31 unshare -Urn env -i …, with no network, scratch HOME and caches, and DO_NOT_TRACK=1. One heavy process ran at a time. The network audit is a ptrace socket tracer, because strace is not installed.
  • Corpora are pinned by SHA in research/bench-3way-20261030/corpora-shas.json: flask 3.1.3, ripgrep 15.2.0, pocketbase v0.40.5, Trail-Code at the 0.28.0 release commit, a mixed corpus of one public repo for each of 10 languages, and a docs corpus built from python/devguide, rust-lang/book and asciidoctor.
  • Tokens are ceil(stdout_bytes / 3.5) for every tool. That is an estimate, not a tokenizer.
  • Cold runs use 3 repetitions, except 1 for any tool whose first run took more than 30 s (Trail-Code and graphify on pocketbase and trailcode). Warm runs take the median of 5 after one discarded warm-up.
  • The callers gold set is the regex oracle of the October protocol (goldlib.py) on 20 seeded targets per corpus. A hit is true when its span contains a gold call site.
  • Query mapping: dctx map find / map neighbors --dir in --edge calls / map skeleton / map hubs. Trail-Code ask / callers / skeleton / map. graphify query / affected --relation calls / explain <file> / GRAPH_REPORT.md.

Not claimed#

  • Whole-session cost or task-level answer quality with a frozen model. Historical fact scores describe raw tool outputs only.
  • Anything about graphify's LLM semantic graph, or Trail-Code's learnings and LSP edges.
  • SWE-bench or agent-run numbers.
  • Equal language depth. dctx's 25 new formats are outline tier: symbols, not call edges.

Changes included in the October baseline#

Call and import edges (19e90a1), byte-stable answers (ce18608), .env omission in pack (6d4deec), outline symbols for 25 formats and plain-text sections (9c61ac9, e0821e3, 839bd45, a32dad3), neighbors depth 4 (0de5ce1), hubs (6bc0cbc), grep (5691234), skeleton (2243c38), path (670e9e3), export (ac8408c), dctx mcp (50bbce4) and a 1 GiB source ceiling (5d26781). Each feature's focused check, and then all 15 checks together on ac8408c, passed on the Linux benchmark host before the benchmark ran.

Independent benchmark, 31.10.2026, run uncapped on the Linux benchmark host#
