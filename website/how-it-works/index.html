How dctx works

Five short animations. Each has a caption with its one point and a text version underneath it when motion is off. Use the Motion toggle in the header to switch between them. Planned features are marked planned.

  • Two scopes, one binary
  • Cost is calls times context

  • The safe path

Two scopes, one binary

The same engine can live in two places on one machine. Knowing which one you are calling avoids most version confusion.

Cost is calls times context

Whole-session cost depends on how many times the model reads the conversation, not only on how big one answer is.

Edit a file, keep the cache

Prompt caches reuse bytes up to the first change. A stable order without timestamps keeps that prefix long.

The giant folder

For a very large folder, the plan is to catalog names once and index only the parts a task needs.

The safe path

The shortest way to find out whether dctx helps your work, without changing several things at once.
