The context engine for AI-assisted software development. dctx sends a model the fewest, most relevant bytes — exact source, in an order that stays the same between turns — so prompts get smaller, prompt caches hit and answers get sharper.

The core belief: prompt-processing efficiency

Every token in front of a model is paid for three times. dctx is built to cut all three.

⏱

Prefill

The model processes every input token before it answers. dctx answers with exact spans and diffs instead of whole files, inside a hard token budget.

♻

Cache hits

Providers serve repeated prompt prefixes for a fraction of the cost. dctx output is byte-for-byte deterministic and canonically ordered, with no timestamps or random ids, so repeated prefixes stay identical and caches hit.

🎯

Attention

Irrelevant tokens make answers worse. dctx ranks, bounds and labels every answer with its precision and freshness. No embeddings, no fragmented chunks, zero RAG defects.

Stop fighting with bash commands

Sharing code context with AI shouldn't require a PhD in shell scripting. Dirty, long bash commands that pick up unwanted files and litter your context are a thing of the past.

  • Manual file concatenation misses critical files
  • Bash one-liners include node_modules and build artifacts
  • No way to track what changed since your last paste
  • Token limits wasted on irrelevant boilerplate
The old way (don't do this): 
find . -type f \( -name "*.ts" -o -name "*.tsx" \) \
  -not -path "./node_modules/*" \
  -not -path "./dist/*" \
  -not -path "./.git/*" \
  -not -name "*.test.ts" \
  -not -name "*.spec.ts" | \
  head -50 | \
  xargs -I {} sh -c \
  'echo "=== {} ===" && cat {}' | \
  pbcopy

With dctx, simply WORK.

Share your context with AI and let it intelligently manage what AI needs to see and what it doesn't.

# Copy your project context to clipboard
$ dctx . -c

# Context ready! Paste into any AI chat.
# 42 files, 15.2KB - intelligently filtered

That's it.

Why dctx changes everything

Not just another file concatenation tool. A fundamentally better approach to AI context.

01

Lightning-Fast Workflow

Intelligent context gathering from any directory in milliseconds. Stop wasting time crafting commands - just point and go.

02

Massive Token Savings

Smart ignore rules filter out node_modules, build artifacts, and irrelevant files automatically. Only what matters reaches the AI.

03

Compounding Efficiency

Intelligent diffing means savings multiply over time. After the initial snapshot, subsequent updates only send what changed - not the entire codebase again.

04

No Vectorization Artifacts

Unlike RAG systems that chunk data into fragments, dctx provides complete files, every time. No truncated functions, no missing context, no malformed code snippets. AI gets the full picture.

05

Smart Navigation, Full Context

Even with entire directories sent at once, AI navigates effortlessly. Every file has a unique ID, with MOD (timestamp), SIZE, and LINES metadata. Clear <FILE_CONTENT_START> and <FILE_CONTENT_END> brackets let AI "skip to" exactly what it needs. No parsing errors. No lost boundaries. AI always knows precisely where each file starts and ends.

Built for the AI-assisted workflow

Every feature designed to save tokens and maximize AI comprehension.

📋

Intelligent Ignore Rules

Global config at ~/.config/dctx/ignore plus per-project .dctxignore files. Automatically excludes node_modules, build outputs, and secrets.

📊

Smart Diff Tracking

Automatic versioned diffs saved to .dctx/ folder. Only send what changed since V1. Major version detection when structure shifts dramatically.

.dctx/context-V1.1-diff.txt
📄

Text Output

Full snapshots written to .dctx/.llmcontext.txt. Keep a history, compare versions, or pipe to other tools. Your context, your way.

⚙

Flexible Templating

Compile custom output templates with dctx template build. Change markers, structure, or format to match your AI's preferences.

dctx template build my-format.dctx_template
⚡

Fast by design

A Rust core that skips ignored trees without entering them, reuses a verified index between runs and answers map queries in a fraction of a second.

🔒

Privacy First

Everything runs locally. Binary state cached in ~/.cache/dctx/. No telemetry, no network requests, no model calls. Your code never leaves your machine.

Power user flags

For when you want to move FAST.

-c, --clipboard Copy output to clipboard
-t, --tree Tree only, no file content
-d, --diff Generate diff from last run
-r, --reset Reset version to V1
-h, --help Show help message
-v, --version Show version info
