## Quick start

```zsh
dctx pack .            # whole project as one structured context block on stdout
dctx pack . --clipboard  # … straight to the clipboard
dctx                   # interactive menu
```

## Map mode

```zsh
# Run from this repository's root; map needs a file target.
dctx map map crates/dctx-cli/src/lib.rs --depth 2
dctx map find "SnapshotConfig"
# Use a stable ID returned by map/find for neighbors, explain and read.
dctx map neighbors 's:crates/dctx-cli/src/lib.rs#SnapshotConfig' --edge calls --dir in
dctx map explain 's:crates/dctx-cli/src/lib.rs#SnapshotConfig'
dctx map read 's:crates/dctx-cli/src/lib.rs#SnapshotConfig' --json
```

## Map verbs

- dctx map map: Outline of a file (m:<path> or a place-relative path) or a symbol and what it contains.
- dctx map find: Ranked symbols, modules, headings and config keys whose name or summary matches QUERY.
- dctx map neighbors: Edges of one node: callers with --dir in --edge calls, callees with --dir out.
- dctx map explain: One node with its signature and summary, no body.
- dctx map read: The verified source text of one node; a long node pages with --cursor.
- dctx map skeleton: Declaration signatures of one file in source order, no bodies.
- dctx map grep: Exhaustive literal search of indexed files, hits grouped by enclosing symbol.
- dctx map hubs: Most-called symbols and per-directory file and symbol counts. No TARGET.
- dctx map path: Shortest edge path (calls, imports, contains; at most 8 hops) between two nodes, or `no path`.
- dctx map export: The whole graph as one deterministic document. No TARGET, no token cap.

- Cold index 0.13-1.20 s on 6 corpora, median of 3 (run 7): https://github.com/Eris-Margeta/dctx/blob/main/docs/research/bench-3way-20261030/results/run7-53f8b6b/aggregate.json

## Install

```zsh
git clone https://github.com/Eris-Margeta/dctx
cd dctx
cargo build --locked --release -p dctx-cli
./target/release/dctx-cli --version   # dctx 1.1.0 (<git sha>)
```

## Exit codes

- 0: ok: the command answered
- 1: no result: the command ran, but the named target or input has no answer
- 2: usage: the arguments are wrong
- 3: index error: the place, source, cache or index could not be opened, read, built or written
