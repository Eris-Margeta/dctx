Maintenance

Free to use. Paid maintenance keeps it healthy.

dctx is Apache-2.0 open source, free for any use including commercial use. A maintenance agreement pays for security response, long-term support and priority work. Paying never changes the license and never closes a feature.

Three ways to support dctx

On request

Supporter

Individuals and teams who want to fund dctx.

  • Sponsorship through GitHub Sponsors
  • Your logo in the README
  • No service commitments

GitHub Sponsors

On request

Team

For one organisation that depends on dctx.

  • Security response: critical 72 hours, high 7 days, medium next release
  • Long-term support: backported fixes for 18 months after 2.0
  • Priority on bug reports
  • A say in the roadmap through a regular review
  • Advance notice of breaking changes
  • Invoice and a written maintenance commitment for procurement

Ask for pricing

On request

Partner

For organisations that build products on dctx.

  • Everything in Team
  • Integration help
  • A named contact

Ask for pricing

What paying never does

  • Paying never changes the license. dctx stays Apache-2.0 for everyone.
  • Paying never closes or paywalls a feature. Every feature stays in the open source project.
  • The core (pack) and every modality stay open.
  • Security reports still go through SECURITY.md, whatever your tier.

The full terms are in MAINTENANCE.md. Trademark use is covered by TRADEMARK.md.
