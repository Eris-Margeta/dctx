Choose your path

One giant folder

You work inside one very large tree, for example a 200 GB monorepo, data or document folder.

you get
Short answers about only the part of the tree you name; the rest is never scanned.
modality
System binary, scoped roots, ignore rules at each root you query.
version
dctx 1.3.1

Setup

  1. Install the system binary from GitHub Releases and verify it against SHA256SUMS.
  2. Write a .dctxignore at each root you will query: data, generated output and archives out (.gitignore is read too).
  3. Decide which sub-roots a task can name: a package, a service, a document set.
  4. Optional: set fail-fast ceilings with DCTX_MAX_SOURCE_BYTES, DCTX_MAX_RECORDS and DCTX_MAX_ENTRIES.

First command

shell
$ dctx map find Config --place packages/service-a --budget 500 --limit 5

What to expect

A bounded page that starts with a # <place> find header and lists one stable id per line. Only the named sub-root is scanned and indexed; dctx cache status --json shows what the cache holds, under a 2 GiB hard cap. A scan over a limit fails with an error instead of returning a partial index.

A real run on the kiosk sample project, recorded from the release binary by capture.py:

~/kiosk · dctx 1.3.1
$ dctx map find greet# kiosk finds:src/util.rs#greet	fn	L2-4s:web/app.ts#renderGreeting	fn	L10-12# exit 0 · 79 bytes · ~23 est. tokens

The pitfall

Pointing an agent at the whole root. Every call then has to scan or index far more than the task needs, and the cache cap can refuse it. Name the sub-root in the task, with --place or by starting in that folder.

Other paths:

  • Many smaller projects
  • Agent builder embedding a library
  • Team or organisation admin

dctx is an advanced tool with several ways to use it. Used well, it cuts irrelevant text from selected tool answers. It does not save tokens by default; savings depend on a system reusing byte-identical, prefix-stable context. Extra calls can add tokens. If you are new, follow the safe path: one project, the system binary, direct CLI commands. Measure before you change anything.

Status: Receipts are planned. The safe path uses CLI commands from a shell or an agent's shell tool.
