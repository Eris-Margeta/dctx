dctx trademark policy

View source · Edit on GitHub · Markdown · TRADEMARK.md · 148 words · updated 7 November 2026

On this page
  • Forks and redistribution
  • What needs permission
  • What is always fine

The "dctx" name and logo are trademarks of Eris Margeta. The Apache-2.0 license covers the code only, not these marks.

Forks and redistribution#

Forks and redistribution of dctx are welcome under Apache-2.0. Keep the LICENSE and NOTICE files, and state clearly what you changed.

What needs permission#

  • Calling a modified build, fork or product "dctx", or any name that suggests it is the official dctx.
  • Using the dctx logo on a modified build, fork, product, website or merchandise.

Name a modified build something else, for example "XYZ, based on dctx". Ask for permission if you want to use the logo.

What is always fine#

  • Unmodified official builds of dctx, redistributed as they are.
  • Descriptive use of the name, such as "works with dctx", "a dctx plugin" or "built on dctx".

To ask for permission, write to info@tejl.com.
